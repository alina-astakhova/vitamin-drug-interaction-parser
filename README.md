# Vitamin-Drug-Interaction-Parser (Drugs.com)

Парсер для сбора информации о взаимодействии лекарств с витаминами с сайта Drugs.com с автоматическим переводом на русский язык.

## 📋 Описание

Проект представляет собой Python-скрипт для автоматического сбора данных о взаимодействии лекарственных препаратов с витаминами. Основные возможности:

- Загрузка списка лекарств, взаимодействующих с указанным витамином
- Сбор детальной информации о каждом взаимодействии
- Автоматический перевод описаний на русский язык
- Сохранение результатов в CSV формате

## 🚀 Быстрый старт 

### Установка зависимостей

```bash
pip install -r requirements.txt
Настройка
Перед использованием необходимо настроить параметры в файле config.py:

python
HEADERS = {
    'User-Agent': 'Your User Agent Here',
    'Cookie': 'Your Actual Cookie Here'  # Получите с сайта drugs.com
}
Как получить куки:

Откройте https://www.drugs.com в браузере

Войдите в систему (если требуется)

Откройте инструменты разработчика (F12)

Скопируйте значение куки из заголовков запроса

Использование
Базовое использование
python
from drugs_parser import DrugsComParser

# Создание парсера для ниацинамида
parser = DrugsComParser(
    vitamin_name="niacinamide",
    vitamin_form="niacinamide"
)

# Запуск парсинга
parser.run()
Расширенное использование
python
# Для разных витаминов
parser_b12 = DrugsComParser("vitamin-b12", "cyanocobalamin")
parser_d3 = DrugsComParser("vitamin-d", "cholecalciferol")
parser_c = DrugsComParser("vitamin-c", "ascorbic acid")

# Запуск парсинга для каждого витамина
parser_b12.run()
parser_d3.run() 
parser_c.run()

📊 Выходные данные
Скрипт создает два файла для каждого витамина:

{vitamin_name}_start.html - исходная HTML страница со списком лекарств

{vitamin_name}_interactions.csv - CSV файл с детальной информацией

Структура CSV файла:

Колонка	Описание
Ссылка	URL страницы лекарства
Витамин	Название витамина
Форма	Форма витамина
Название лекарства	Название лекарственного препарата
Уровень взаимодействия	Уровень взаимодействия (-1, -2, -3)
Описание (пользователь)	Описание на английском для пользователей
Описание (пользователь, рус)	Перевод описания на русский
Описание (профессионал)	Профессиональное описание на английском
Описание (профессионал, рус)	Перевод профессионального описания
⚙️ Конфигурация
Основные параметры в config.py:

HEADERS - HTTP заголовки для запросов

REQUEST_DELAY - задержка между запросами (в секундах)

TRANSLATE_TO_RUSSIAN - включить/выключить перевод
